# 楽天ひかり環境における自宅ネットワーク構築

## 概要

2026年8月現在、自宅では楽天ひかりを契約しています。

ネットワーク機器には、TP-Link製Wi-Fiルーターと、Ubiquiti製のCloud Gateway Ultraを使用しています。

Cloud Gateway Ultraでは、端末管理、DHCP、ファイアウォール、ネットワークの監視などを行っています。

## ネットワーク構成

現在の通信経路は次のとおりです。

ONU（楽天ひかり）  
↓  
TP-Link Wi-Fiルーター  
↓  
Ubiquiti Cloud Gateway Ultra  
↓  
パソコン・サーバー・その他の端末

TP-LinkルーターとCloud Gateway Ultraの両方がルーターとして動作しているため、現在は二重ルーターおよび二重NATの構成となっています。

## 発生した問題

当初は、ONUとCloud Gateway Ultraを直接接続し、Ubiquiti製品のみでネットワークを構成することを検討しました。

しかし、楽天ひかりで提供されているIPv4 over IPv6サービス「クロスパス」をCloud Gateway Ultraで設定したところ、次の問題が発生しました。

- IPv6ではインターネットへ接続できる
    
- IPv4ではインターネットへ接続できない
    
- 設定変更後に通信速度が大幅に低下する
    
- 接続方式やゲートウェイ設定を変更しても安定しない
    

このため、Cloud Gateway Ultra単体での運用を一旦断念しました。

## 暫定的な対処

クロスパスに対応しているTP-LinkルーターをONUの直下に設置し、TP-Link側で楽天ひかりへの接続処理を行う構成へ変更しました。

Ubiquiti Cloud Gateway UltraはTP-Linkルーターの下流に配置し、自宅内の端末管理、DHCP、ファイアウォール、トラフィック監視などを担当させています。

この構成では二重NATとなりますが、現在のところ通常のWeb閲覧、動画視聴、オンラインゲーム、サーバーへの接続などに大きな問題は発生しておらず、通信速度も実用上十分な値が出ています。

## 今後の課題

将来的には、TP-Linkルーターを経由せず、Cloud Gateway Ultraのみで楽天ひかりのIPv4 over IPv6接続を確立したいと考えています。

今後は、次の項目を継続して検証する予定です。

- UniFi OSおよびUniFi Networkのアップデート内容
    
- DS-Liteのゲートウェイアドレス設定
    
- IPv6アドレスおよびプレフィックスの取得状況
    
- WAN側のSLAAC・DHCPv6設定
    
- ファイアウォールおよびDNS設定
    
- 二重NATを解消した場合の通信速度と安定性
    

現時点では安定性を優先し、TP-LinkルーターとCloud Gateway Ultraを併用する構成で運用しています。

## この構築で経験したこと

- IPv4、IPv6、IPv4 over IPv6の基本的な仕組み
    
- DS-Lite環境の接続確認
    
- 家庭用ルーターと業務向けゲートウェイの併用
    
- DHCP、NAT、二重ルーター構成の理解
    
- 接続障害発生時の切り分け
    
- 暫定対処後の通信速度および安定性の確認
