# VM1(Hermes Agent)

- CPU:4コア
- RAM:16GB
- SSD100GB
- ubuntu server

このVMでは、Hermes Agentを動かしています。
主にVPSで動かすためのテストをこっちでやっています。
AIモデルは、APIを使用していろんなモデルを試しています。

Hermes Agentでいろんなモデルを使用することで、どのモデルが何を得意とするのかが良くわかって面白いです。

自作Skillは、一度こちらでテストを行ってからしっかり自分が想定した挙動を見てから24時間のメインサーバーへSkillとAgentを持っていくようにしています。

例えば、検索だったらGrokの検索とポストをまとめるのがうまいです。
反対に文章生成特に日本語だったらClaudeの方がうまいです。

こんな感じで適材適所で良い感じに使う分には、本当にHermes Agentが使いやすくて助かっています。

スペックをここまで上げないと行けない理由が１つありまして、16GBくらいないとAgentがSkillを生成や加工をしている時に８GBだと暴走して止まらなくなってしまうので、16GBを振っています。

## VM2(n8n)

- CPU:2 
- RAM 4GB
- SSD 100GB
- ubuntu server

n8nには、定期タスクを回すようにしています。
現在は、WordPressのAnalyticsは、こちらで処理をしています。
定期的に情報だけ抜き取りAI処理をして、ファイルを残していく形にしています。
MCPServerのデータベースに送ったりする時もこちらを使用して行っています。
ゆくゆくは、VM1(Hermes Agent)と繋げて自動でワークフローを構築して定期タスクをやってもらいたいなと思っています。
こちらもまだテスト段階なので今現在(2026年8月現在)まだVPSへの導入は、していません。


## VM3(MCPServer)

- CPU:4
- RAM:10
- SSD:100GB
- ubuntu server

最近一番自分にホットなのがこのMCPServerです。
n8nでも最近繋がるようになって大変助かっています。

このMCPを独立させている理由は、いろいろ合ってVMを検証のためVMを頻繁に再構築するため、影響を受けないようMCP Serverを別VMとして分離しています。

postgresSQLもわかりやすくこちらのServerに入れてあります。
今の所WordPressのアクセス解析やリライトの候補など限定的なテスト段階でまだまだ実用的じゃないので24時間サーバーの方には、持っていっていません。
